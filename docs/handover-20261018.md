## 3. 关键决策账本（实现批新增；文档层决策 15 条见 git 历史 handover 首版）

16. **timed ask 缩围（F6）**：宿主 `dsh-tool-ask-user` 原生支持 timeout（超时=pending 可续答）→ 插件只做检测+指引、零包装层——依据=asar 源码实查；影响=F6 施工量趋零。

18. **边界执法主体=宿主 sandbox**：三档+escalation 审批宿主已完整实现 → 插件净增量=边界判定（词法归约防 `../` 前缀逃逸，单测抓获真实洞）+写动作对账遥测——与「拦截层外置」既有拍板同构。
19. **layered 跨插件契约**：优先序 `SHISANUO_LAYERED_DIR > $DSH_HOME/dsh-custom/layered > 包内出厂`；mtime 缓存=热生效；页面停用（layered-state.json）→引擎跳过注入——影响=两仓形成单向依赖（dsh-custom 是编辑面，shisan-xinuo-core 是装载面）。
20. **待裁定项按建议默认先行**：user-prompt 命名/装配序/layered 开放编辑均按迭代文档建议值实现（§4 可翻案，翻案成本低——命名与装配序各一处常量）。
21. **诚实占位**：页面 ⑧运行时治理面板与 ⑥备份目录项不做假数据——数据面（运行时 exec-log API）未暴露前只显示说明文字。
