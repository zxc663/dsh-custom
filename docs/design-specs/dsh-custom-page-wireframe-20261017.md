# DSH自定义 · 页面完全草图（基于已确认功能清单 · 纯布局稿）

> 版本：2026-10-17 · v1。性质：**页面完全草图**——只画「页面长什么样、有什么控件、什么状态」，不含迭代分期与功能规划（那是迭代推进文档的职责）。
> 依据：用户确认的功能清单＝①装配概览 ②提示词中心（常驻核心/我的提示词/渐进加载层）③接管官方 ④作用域规则 ⑤快照与回滚 ⑥备份管理 ⑦审计与状态 ⑧运行时治理（只读）⑨设置。
> 反人类修复：现有页面问题与对应处理逐区列在「修复对照」中。

## ① 装配概览（默认入口）

```
┌──────────────────────────────────────────────────────────────────┐
│ [渲染全文 | 分区源码]                          [复制全文] [导出]  │
├──────────────────────────────────────────────────────────────────┤
│ # 段列表（分区源码视图）                                          │
│ ┌──────────────────────────────────────────────────────────────┐ │
│ │ 001 order=-2000  shisanxinuo:core-discipline  [ours] 3.2KB ▾ │ │
│ │ 002 order=300    shisanxinuo:live-status    [ours] 0.4KB ▾ │ │
│ │ 003 order=0      identity                 [official] 0.8KB ▾│ │
│ │ …                                                             │ │
│ └──────────────────────────────────────────────────────────────┘ │
│ 变量表（带值）：{{model}}=longcat-2.5-preview-free …              │
│ 沙箱与审批策略上下文：mode=danger-full-access · L3=记录            │
└──────────────────────────────────────────────────────────────────┘
```
组件：视图切换、段列表（顺序/段名/归属徽标/字符数/展开）、变量表带值、沙箱审批上下文、复制/导出。
状态：加载中骨架；空段列表说明；渲染失败→容错渲染＋「原文呈现，不代表渲染成功」标注。
修复对照：段归属不明（其他外部一律标 other，不冒充官方）；变量无值不展示为空白。

## 通用状态与规则

- 六态覆盖：每页 loading/empty/error/edge/disabled/success 都有明确表现。
- 所有高影响操作：可解释（结果行）、可回滚（快照）、可留痕（audit）。
- 键盘可达、焦点可见、色彩不作唯一状态通道、错误靠近发生位置。
